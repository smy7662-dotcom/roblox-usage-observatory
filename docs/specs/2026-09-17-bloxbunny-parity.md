# Roblox 이용량 관측 대시보드 — BloxBunny 기능형 설계

## 목표

Roblox 플랫폼과 게임별 이용량을 한국어 화면에서 탐색·비교·추적할 수 있는 공개 대시보드를 구축함.
공개 관측값과 실제 보고값만 사용하며, DAU 환산·매출 추정·빈 구간 보간은 하지 않음.

## 확정된 전제

- 사용자는 Roblox 전체 이용량보다 게임별 이용량과 게임 발견·성장 흐름을 함께 보고 싶어함.
- 현재 사이트는 정적 HTML 대시보드이며 플랫폼 hourly/daily, 보고 포인트, 게임별 daily 데이터를 보유함.
- 로컬 아카이브에는 Early Shift 게임별 일별 자료, BloxScout 게임별 hourly/history 자료, RoMonitor 상위 게임 스냅샷이 추가로 있음.
- BloxBunny의 공개 기능 구조를 재구현하되, 원본 코드·비공개 DB·브랜드 자산을 복제하지 않음.
- 모든 사용자 노출 문구는 한국어로 작성함.
- 데이터 수집 공백은 공백으로 표시하고 추정·보간하지 않음.

## 핵심 사용자 흐름

1. 개요 화면에서 최근 플랫폼 CCU, 추적 게임 수, 게임별 합산 CCU, 최근 상승 게임을 확인함.
2. 게임 검색 후 상세 화면에서 현재 CCU, 성장률, 평균·피크 CCU, 방문·즐겨찾기 변화, 관측 공백을 확인함.
3. 비교 화면에서 여러 게임의 CCU 시계열과 관측 기간을 겹쳐 비교함.
4. 발견 보드 화면에서 Roblox 보드별 진입·이탈·체류시간과 최근 변동을 확인함.
5. 데이터 범위 화면에서 수집 시작일, 마지막 수집일, 수집 주기, 공백을 검증함.

## 1차 구현 범위

### 화면

- 개요
- 게임 목록·검색
- 게임 상세·역사 차트
- 게임 비교
- 발견 보드 분석
- 제작자·장르 집계
- 데이터 범위·수집 상태

### 지표

- 플랫폼 CCU: hourly/daily/weekly/monthly 평균·피크
- 게임 CCU: 관측된 평균·피크·현재값
- 게임 성장률: 비교 가능한 실제 관측 구간의 변화율
- 추적 게임 수와 관측일 수
- 발견 보드 진입·이탈·관측 체류시간
- 장르·제작자별 추적 게임 CCU 합계
- 방문수·즐겨찾기 변화: 원자료가 있을 때만 표시

### 데이터 구조

- 원시 자료와 정규화 자료를 분리함.
- 각 레코드에 `source`, `observed_at`, `granularity`, `coverage`를 유지함.
- 집계 화면은 원시 관측값에서 계산하며, 공백은 null/단절로 유지함.
- 수집기 실행 결과는 날짜별 스냅샷으로 남기고 중복 키는 `(universe_id, timestamp, source)`로 제거함.

## 데이터 수집 계획

- 기존 플랫폼 데이터와 게임별 아카이브를 정규화함.
- 공개적으로 접근 가능한 게임 목록·CCU·메타데이터를 주기적으로 수집하는 스크립트를 추가함.
- 발견 보드는 보드 이름·순위·게임 ID·관측 시각을 저장하고, 연속 관측 사이의 진입·이탈 이벤트를 계산함.
- 수집기 실패, 오래된 자료, 공백을 UI에서 구분함.
- 실제 자동 실행은 수집기와 정적 데이터 빌드 경로를 분리하여 재실행 가능하게 함.

## 제외 범위

- Roblox 계정 전용 Creator Analytics 데이터
- BloxBunny의 유료 플랜·로그인·비공개 API 재현
- 모델링한 DAU, 매출 추정, 체류시간 추정
- 과거 공백 보간
- 원본 사이트의 코드·브랜드·문구 복사

## 성공 기준

- 첫 화면에서 플랫폼 현재값·관측 범위·데이터 신선도를 10초 안에 확인할 수 있음.
- 게임 하나를 검색해 실제 관측 시계열과 관측 공백을 확인할 수 있음.
- 여러 게임을 선택해 동일 시간축으로 비교할 수 있음.
- 발견 보드별 진입·이탈·체류시간의 계산 기준을 화면에서 설명함.
- 모든 핵심 화면과 상태(로딩·빈 데이터·오래된 데이터·수집 실패)가 한국어임.
- 기존 CSV/JSON 다운로드와 no-estimate 정책이 유지됨.

## 구현 순서

1. 데이터 정규화와 수집기 스키마 확장
2. 한국어 공통 레이아웃과 개요 화면 재구성
3. 게임 상세·시계열·비교 화면 추가
4. 발견 보드 이벤트 집계 화면 추가
5. 제작자·장르·데이터 범위 화면 추가
6. 로컬 기능 검증 후 공개 배포

## 검증 위험

- Roblox 과거 CCU 공식 API가 없으므로 게임별 시계열은 수집된 공개 관측 범위에 한정됨.
- 자료원마다 수집 대상 게임 집합과 주기가 달라 출처 경계를 숨기면 안 됨.
- 정적 호스팅만으로는 서버 스케줄 수집이 보장되지 않으므로 수집 실행 경로와 배포 갱신을 별도로 검증해야 함.
